# June's LazyVim Config

## LazyVim

Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Neogit status

After a successful push, the open status view refreshes again after two seconds
to let Neogit's commit-list cache expire. This clears stale “Unmerged into”
entries without closing and reopening the view. Use `Ctrl+r` in NeogitStatus
to refresh manually.

## Neovide project tabs

Native macOS tabs are enabled in `~/.config/neovide/config.toml`.

Use `Cmd+Ctrl+N` for the Editors switcher, or `Cmd+Shift+[` / `Cmd+Shift+]`
to cycle native tabs. These are separate from Neovim's own tab pages.
